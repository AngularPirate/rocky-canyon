# Rocky Canyon

A 17-week base training block — September 7, 2026 to January 3, 2027 — built toward
Race to Robie Creek 2027, then a marathon, then trail ultras.

**https://angularpirate.github.io/rocky-canyon/**

## What this is

A phone-first training app. Five tabs:

- **Today** — the session in front of you, with exercises, sets, reps, target weights and clock times
- **Week** — the seven-day view; tap any session to open its full detail
- **Log** — planned vs. logged volume, session streak, and a hip-pain trend strip
- **Coach** — an AI coach fed the plan and the training log (live version only)
- **Plan** — paces, hip triage, full gym prescriptions, trail work, missed-session rules, key dates

This is a read-only review copy. Logging and the coach run only in the private version.

## The constraints it was built around

Runs happen in the morning and must be finished by 7am. Hockey Tuesday nights. Run club Thursday at
5:50am. Gym in the evening. Weekends are unpredictable. Bilateral hip labral tears from 2023, managed
conservatively — so squat and hinge depth is capped at pelvis-neutral, joint pain is held to a 2/10
ceiling, and intensity is introduced in a deliberate order: strides, then short hill sprints, then
progression runs, then threshold. No track intervals until January.

The one rule everything else falls out of: **the quality run, hockey and the long run never sit
within 24 hours of each other.**
